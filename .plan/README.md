# Plan Naming Convention & Directory Guidelines

All plans, design documents, and roadmaps in this repository must be saved in the `.plan/` directory using the following naming convention:

```text
YYMMDD-[utc time]-[plan name].md
```

### Components
- **`YYMMDD`**: 2-digit year, 2-digit month, 2-digit day (e.g., `261001` for 2026-10-01).
- **`[utc time]`**: Current UTC time in `HHMM` format (e.g., `1242`).
- **`[plan name]`**: Concise, descriptive plan name in snake_case or kebab-case (e.g., `migration_plan`).

### Examples
- `.plan/261001-1242-migration_plan.md`
- `.plan/261001-1400-core_physics_verification.md`
